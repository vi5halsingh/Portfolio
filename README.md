# 🚀 Vishal's Portfolio

- Responsive layout with smooth scrolling
- GSAP animations & scroll-triggered effects

- Minimalist aesthetic

## 🛠️ Technologies

- Tailwind CSS
- GSAP/ScrollTrigger
- FormSubmit/Web3Forms
